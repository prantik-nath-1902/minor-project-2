# HyenaTech – Responsive Product Landing Page

## About the Project

HyenaTech is a responsive laptop product landing page developed as part of the **Web Development – Week 02 Minor Project**.

The website showcases different laptop models, their prices, features, and benefits through a clean and user-friendly interface. It is designed to provide visitors with a simple way to explore laptop products across desktop, tablet, and mobile devices.

## Objectives

* Build a responsive product landing page.
* Learn and implement HTML5 and CSS3.
* Use Bootstrap's grid system to create responsive layouts.
* Create attractive product cards and navigation links.
* Improve UI/UX through consistent colours, spacing, and hover effects.
* Organize project files and prepare the project for GitHub.

## Features

* **Responsive Navigation Bar:** Provides links to different sections of the website.
* **Hero Section:** Displays a welcome message, background image, and call-to-action button.
* **Features Section:** Highlights important laptop features using icons and cards.
* **Benefits Section:** Explains the advantages of exploring products on HyenaTech.
* **Customer Reviews:** Displays sample customer feedback in review cards.
* **Product Section:** Showcases laptop models, images, and prices.
* **Interactive Hover Effects:** Adds visual feedback to buttons and cards.
* **Footer:** Includes copyright information and links to other pages.

## Technologies Used

* HTML5 – Website structure and content.
* CSS3 – Styling, animations, and responsive design.
* Bootstrap 5 – Responsive grid system and navigation components.
* Bootstrap Icons – Icons for features and benefits.
* JavaScript – Bootstrap's responsive navigation functionality.

## Responsive Design

The website uses Bootstrap's responsive grid classes to arrange product cards and content according to screen size. The layout is designed to adapt to mobile phones, tablets, and desktop screens.
